## 💬 서비스 의미

> **Job + is = 지금 나에게 필요한 Job은 무엇일까?**

Job.is는 수많은 채용 공고를 직접 찾아보는 대신,  
사용자에게 필요한 **채용 공고·커리어 뉴스·청년 지원 정보를 선별하여 매일 제공**하는 AI 취업 큐레이션 서비스입니다.

단순히 많은 정보를 보여주는 것이 아니라  
**사용자에게 필요한 기회를 찾아 전달하는 것**을 목표로 합니다.

---

## 💡 서비스 개요

### 문제

취업 준비 과정에서 사용자는 사람인, 잡코리아, 링커리어 등 여러 플랫폼을 오가며  
매일 수많은 채용 공고를 탐색하고 비교해야 합니다.

정보가 부족한 것이 아니라,  
**너무 많은 정보 속에서 나에게 필요한 정보를 찾기 어렵다는 것**이 문제였습니다.

또한 기존 AI 추천 서비스는 추천 결과를 제공하더라도  
**왜 이 공고가 나에게 적합한지에 대한 근거가 부족**해 사용자가 다시 직접 탐색하고 비교하게 됩니다.

### 해결

> **"찾지 마세요, 받으세요."**

Job.is는 사용자가 직접 정보를 찾아다니는 탐색형 서비스에서 벗어나  
**매일 아침 소수의 맞춤 정보를 받아보는 큐레이션 방식**을 제안합니다.

사용자의 프로필과 관심사를 바탕으로 채용 공고를 선별하고,  
각 추천 결과에 **추천 이유와 적합 포인트**를 함께 제공하여  
사용자가 빠르게 판단하고 행동할 수 있도록 설계했습니다.

## 🔍 문제 정의 및 검증

### 01. 정보 과밀과 탐색 피로

실질 취준생은 100만 명 이상이며,  
잡코리아 MZ 구직자 576명 설문에서 **84.5%가 정보 수집에 어려움을 겪는다**고 답했습니다.

대형 채용 플랫폼은 광고·배너·수많은 공고가 한 화면에 노출되면서  
정보가 부족한 것이 아니라 **복잡한 UI 속에 필요한 정보가 묻히는 문제**가 발생합니다.

### 02. 근거 없는 AI 추천

채용 공고는 기업이 전달하고 싶은 정보 중심으로 길게 구성되어 있고,  
기존 AI 추천 역시 사용자가 **왜 해당 공고를 추천받았는지 이해하기 어려운 경우**가 있습니다.

결국 사용자는 추천 결과를 확인한 뒤에도  
다시 공고를 탐색하고 비교하는 과정을 반복하게 됩니다.

### 03. 사용자 검증

- 취준생 **8명 심층 인터뷰**를 통한 실제 페인포인트 확인
- 사전예약 랜딩 페이지를 활용한 **Fake Door Test** 진행
- Google·Meta 광고를 집행하여 약 **10%의 이메일 사전예약 전환율** 확인
- 초기 사용자 수요 및 문제 가설 검증

### 핵심 Pain Point

> **"정보는 넘치는데, 내 자리는 안 보인다."**

- 여러 채용 플랫폼을 매일 순회하며 공고 탐색
- 일평균 1시간 이상 공고 탐색 및 비교에 소요
- 추천 결과가 많아도 **왜 나에게 맞는지 알기 어려움**
- 사용자의 행동과 선호가 다음 추천에 충분히 반영되지 않음

## 🚀 솔루션

### **"찾지 마세요, 받으세요."**

Job.is는 기존의 **탐색 중심 채용 서비스**를  
**개인 맞춤형 큐레이션 서비스**로 전환합니다.

**많이 보여주는 것보다 필요한 것을 보여주는 것**에 집중하여  
사용자가 매일 수많은 공고를 탐색하는 시간을 줄이고,  
자신에게 적합한 기회에 빠르게 접근할 수 있도록 했습니다.

---

### 📬 오늘의 추천

매일 아침 사용자의 직무와 조건에 맞는  
**채용 공고·커리어 뉴스·청년 혜택**을 소수의 콘텐츠로 제공합니다.

많은 정보를 나열하는 대신 브리핑 덱 형태로 구성하여  
비교 피로와 인지 부담을 줄였습니다.

### 💡 추천 이유

2단계 매칭 엔진을 통해 추천 후보를 선별합니다.

> **벡터 검색 → 후보 20건 → LLM 선별 → 최종 5건**

각 공고마다 **추천 이유·적합 포인트·주의점**을 함께 제공하여  
단순 추천을 넘어 사용자가 추천 결과를 이해하고 판단할 수 있도록 했습니다.

### 🔄 피드백 루프

사용자의 좋아요·저장·지원 등의 행동 신호와  
이력서 정보를 다음 추천에 반영합니다.

사용할수록 사용자에 대한 정보가 축적되어  
**개인화된 추천 경험이 강화**되도록 설계했습니다.

### 👤 온보딩 · 저장 · 지원 관리

온보딩 과정에서 유저 프로필과 선호 정보를 입력하고,  
추천 상세 화면에서 **저장 및 지원까지 원클릭으로 연결**했습니다.

정보 탐색부터 실제 지원까지의 불필요한 단계를 줄였습니다.

## 🎨 디자인

### Design Goal

> **많은 정보를 보여주는 서비스가 아닌,  
> 필요한 정보를 빠르게 이해하고 행동할 수 있는 서비스**

Job.is의 UI/UX는 정보의 양을 줄이고  
사용자가 중요한 정보에 집중할 수 있도록 설계했습니다.

### Brand Identity

AI 기반 개인 맞춤형 커리어 서비스의 특성을 반영하여  
**신뢰감과 기술적인 이미지를 동시에 전달하는 브랜드 아이덴티티**를 구축했습니다.

### Design System

서비스 전체의 일관된 UI를 위해 디자인 시스템을 구축했습니다.

- **Color**
- **Typography**
- **Layout**
- **Icon**
- **Component**
- **Design Token**

### UI/UX Design

사용자가 직접 여러 채용 플랫폼을 탐색하지 않아도  
자신에게 필요한 정보를 빠르게 확인할 수 있도록 주요 화면을 설계했습니다.

- 온보딩
- 오늘의 추천
- 채용 공고
- 공고 상세
- 커리어 뉴스
- 청년 정책 및 지원 정보
- 저장
- 지원 관리
- 알림 설정
- 마이페이지

> **약 60개의 PC Web UI 화면 디자인**
